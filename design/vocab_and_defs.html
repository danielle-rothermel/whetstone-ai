Identity partitions

Static computation

Node definitions, variable assignments, provider-call configuration, evaluation-procedure configuration, and declared graph wiring contribute to Graph Hash.

Evaluation meaning

Eval Config, task and repeat plan, role, authority, purpose, candidate, and run or step scope belong to the evaluation intent and its evidence.

Physical execution

Provider request identity, policy identity, attempt ordinal, durability mode, timing, and transport evidence belong to provider-attempt evidence.

System invariants

  • Each behavior has one production implementation and one authoritative persisted representation.
  • Claims are persisted before effects; terminal binding is ownership-checked and replay-safe.
  • Missing, failed, refused, and numeric zero remain distinct states.
  • Official evidence requires an authorized official role at execution time; reporting cannot relabel internal evidence.
  • Provider execution is described honestly as provider-idempotent or at-least-once.
  • Publication is a projection of canonical evidence, never a competing authority.
